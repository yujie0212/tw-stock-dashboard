# 台股選股監控台

AI 台股智慧選股與監控系統的網站前端示範頁。

> 目前是**示範版本**：頁面上的股票、價格與數字都是範例資料，尚未接上系統實際輸出。

## 頁面內容

- **頂部狀態列**：日期、收盤後流程狀態、測試頻道或正式推播
- **今日摘要**：今日選股數量與推播頻道
- **今日選股**：短線、波段、中長線分頁，含收盤價、漲跌、選入原因與法人動向
- **大盤概況**：加權指數、櫃買指數、三大法人買賣超
- **策略驗證關卡**：短線與波段在三段期間的回測結果與通過條件
- **每日排程**：08:07 盤前訊息、18:45 收盤後流程
- **歷史回補進度**：行情、法人、指數、回測

## 檢視方式

純靜態頁面，不需要建置。直接用瀏覽器打開 `index.html`，或開啟 GitHub Pages（Settings → Pages → Deploy from a branch → `main` / root）。
